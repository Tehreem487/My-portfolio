# Tehreem Khan — Dreamy Portfolio

A whimsical, responsive React + Vite portfolio with:
- Falling flower/petal animation
- Floating butterflies
- Sparkles
- Glassmorphism cards
- Scroll reveal animations
- Dark/light theme
- Responsive mobile navigation
- Magical loading screen
- Custom cursor + cursor ring on desktop
- Project category filters
- Interactive glowing project borders
- Floating quote/orbit section
- Magnetic-style button shine effects
- 14 project cards
- Internship experience section for 2 letters
- ICS education section
- Resume download area
- Contact form UI

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Replace these placeholders

1. Put your real CV at `public/resume.pdf`
2. Replace the two internship placeholders in `src/App.jsx`
3. Replace `your-email@example.com`
4. Add your LinkedIn and GitHub URLs
5. Replace each project's `Live Demo` and `GitHub` links
6. If you want project screenshots, add them to `public/images/` and change the project card visuals.

## Deploy

```bash
npm run build
```

The generated `dist` folder can be deployed to Vercel, Netlify, or another static host.
